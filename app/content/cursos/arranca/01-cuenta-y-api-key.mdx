## Qué vas a lograr

Una cuenta en EasyBits y una API key `eb_sk_live_…`. Esa llave es lo que tu agente usa para hablar con la plataforma: la misma abre archivos, cajas, bases de datos y el endpoint MCP.

## Pasos

1. Entra a [easybits.cloud/login](/login). Con Google o con tu correo (te llega un enlace mágico).
2. Ve a [Desarrollador → API keys](/dash/developer).
3. Crea una llave. Ponle nombre por **quién la va a usar** ("claude-code-laptop", "cursor"), no por fecha: cuando revoques una, sabrás a quién le quitaste acceso.
4. Cópiala ahora. Solo se muestra una vez.

<Callout type="info">
El plan gratis (Byte) incluye 1 caja, 3 bases de datos y almacenamiento de archivos. No pide tarjeta.
</Callout>

## Qué acabas de aprender

Una API key en EasyBits no es "una llave de la API": es la identidad de tu agente. Todo lo que hagas en las siguientes lecciones se registra a nombre de esa llave — y esta academia lo usa como evidencia: esta lección se marca hecha **cuando tu cuenta tiene una llave activa**, no cuando das clic en "listo".

## Siguiente

Conecta el MCP para que tu agente use la llave sin que copies nada más.
