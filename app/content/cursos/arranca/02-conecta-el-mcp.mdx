## Qué vas a lograr

Que tu agente sepa usar EasyBits: crear cajas, subir archivos, consultar bases de datos. Con un comando, sin configurar conectores.

## Pasos

**Claude Code, Codex, Cursor y cualquier agente con terminal** (lo recomendado):

```bash
npx skills add https://easybits.cloud
```

Instala las skills de EasyBits (`easybits-cli`, `easybits-sandbox`, `easybits-agent`…). Le enseñan a tu agente a usar el CLI `easybits`, que trae `--json` en cada comando. La primera vez, el agente corre `easybits login --json` y te pasa una liga para entrar con tu cuenta. Lo demás lo hace él.

**Claude.ai (web/app)**, que no tiene terminal: Ajustes → Conectores → añadir `https://www.easybits.cloud/api/mcp` y autorizar con tu cuenta.

<Callout type="info">
¿Tu cliente sólo habla MCP? El endpoint sigue ahí: `https://www.easybits.cloud/api/mcp` con `Authorization: Bearer eb_sk_live_TU_LLAVE`. Después de conectarlo, reinicia la sesión: los clientes MCP piden la lista de herramientas al arrancar y no la refrescan.
</Callout>

## Hazlo con tu agente

Pégale el prompt de abajo. Si te pasa la liga, entras y después te responde con tus archivos (aunque la lista esté vacía), ya está conectado.

<Callout type="warning">
Si el agente dice "no puedo hacer eso", no le creas a la primera: pídele que corra el comando. Un agente puede negar capacidades que sí tiene. El error real (401, comando no encontrado) sí es información.
</Callout>

## Qué acabas de aprender

Una skill es un manual que tu agente lee cuando lo necesita: cuesta casi nada de contexto hasta que la usa, y el CLI hace el trabajo. Esta lección se marca hecha cuando **tu cuenta autoriza una sesión real**: el login del CLI, tu conector de Claude.ai o una llamada con tu llave.
