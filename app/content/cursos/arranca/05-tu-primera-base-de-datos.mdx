## Qué vas a lograr

Una base de datos SQL (libSQL, compatible con SQLite) que tu agente crea y consulta. Es donde va la memoria que debe sobrevivir a la conversación.

## Pasos

Desde el agente con el prompt de abajo. Desde la UI: [Desarrollador → Bases de datos](/dash/developer/databases).

Por SDK:

```ts
const db = await eb.createDatabase({ name: "notas" });
await eb.execDatabase(db.id, [
  { sql: "CREATE TABLE notas(id INTEGER PRIMARY KEY, texto TEXT)" },
  { sql: "INSERT INTO notas(texto) VALUES ('primera'), ('segunda')" },
]);
const rows = await eb.queryDatabase(db.id, "SELECT * FROM notas");
```

## Hazlo con tu agente

Cierra la conversación, abre otra y pídele *"¿qué notas tengo?"*. Si las lee de la base, ya tiene memoria que no depende del contexto.

<Callout type="info">
Cada base es un namespace aislado. Un agente que atiende a varios clientes puede tener **una base por cliente** — eso es multi-tenant, y es el corazón de la ruta *Vende tu agente*.
</Callout>

## Qué acabas de aprender

Archivos para lo que se sirve, SQL para lo que se consulta. Con esta lección tu cuenta tiene llave, MCP, archivo, caja y base: **el kit completo**. Esta lección se marca hecha cuando **tu cuenta tiene una base de datos**.
